# contexto/

Insumos y **contexto para la IA** (Claude Code y afines): requisitos, fuentes,
decisiones de diseño, notas de investigación. **No es parte de la app** —no se
sirve por HTTP (está bloqueada por `.htaccess`) y no la carga ningún código.

Ponla aquí para que, al desarrollar con asistencia de IA, el modelo tenga el
porqué del proyecto a mano sin ensuciar el código. Lo que deba perdurar como
regla va en `CLAUDE.md`; lo que sea estado o decisión fechada, en `MEMORY.md`.
